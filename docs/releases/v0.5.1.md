## FX Unleashed 0.5.1

Updates itself from 0.5.0: the banner (or the About tab) offers it, one click installs it, **Roll back** is there if you want the old one.

### What's new

- **Custom firmware.** What we called the "wheel app" is now the **custom firmware**, everywhere. The setup guide has the right SimPro steps
  (**Settings > Update > Manual Firmware Flash**, then **Flash** on the FX PRO row), and the plugin's own texts say the same.
- **Dash designer: Wheel traffic.** A new pill and tab show what your dash sends to the wheel over a demo lap: the average and busiest second
  against the screen's 25 KB/s, flashing updates, which elements send the most (click one to select it), a graph, and **Fix them** for text on a
  border line. The same three gates the `/create-dash` command uses, live while you edit. It can measure with rectangles or with the RAM patch.
- **Updates.** The plugin looks for updates at every start and every 6 hours while SimHub is open (it was once a day), and the update banner is shorter.
- **Library.**
  - The dashes library opens expanded, and a dash you already have in your folder shows as installed instead of offering Install again.
  - Screensavers have their own library on the Idle tab, also open by default, and **Share...** on your own screensavers packages them for the library.
  - The Package dialog asks **What is it?** (dash or screensaver), the submit form asks the same, and the bot checks they agree.
  - The Package dialog no longer talks about pull requests or a maintainer adding it: a package that passes the checks is published on the spot.
- **SimHub device.** A section brightness of 0 in SimHub now means off (it left the LEDs dimly lit). The device's mapping is tested against the wheel model.
- **Lights guide.** New: [the FX Pro in SimHub's Devices and ATSR-Hub](https://fxunleashed.com/docs/lights/), with the ATSR-Hub profile to download
  (it is also in this zip, renamed for FX Unleashed inside) and where each SimHub light lands on the wheel.
- **The guide.** The screen check says what a green card and a solid red screen mean and where to go next; the dash button is no longer called "button 40".

Everything else is as in [0.5.0](https://github.com/fxunleashed/fx-unleashed/releases/tag/v0.5.0).

### Requirements

SimHub 9.11 or newer, SimPro Manager 3 (V3.2.2 tested) for standard mode, an FX Pro or GT Neo. Tested by the maintainer on one FX Pro on an Alpha EVO
base: other bases, wheels and games may behave differently, so please report what you find (Discord or GitHub issues).

### Install and update

From 0.5.0: let it update itself (About tab). New install: close SimHub, copy `User.FXProRpmSync.dll` from the zip into your SimHub folder, start SimHub,
turn the plugin on. Guide: https://fxunleashed.com/start/

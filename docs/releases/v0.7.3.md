## FX Unleashed 0.7.3

Updates itself from 0.5.x, 0.6.x and 0.7.x: the banner (or the About tab) offers it, one click installs it, **Roll back** is there if you want the old one.

### What's new

**Dash designer**

- **Pages, all of them.** A new **Pages** tab shows every set of pages a dash has (up to four, each flipped on its own with Next
  page 1-4; Next page flips them all): add and remove pages and whole sets, rename them, reorder pages (their elements follow),
  and click the number beside a page to select what's on it. New elements can go straight onto the page you're looking at. The
  top bar picks the page of each set separately, and Exact, Demo lap and the wheel follow. Dashes with more than one set of pages
  (the Aston Martin) can now be edited page by page.
- **Fonts you can read.** The screen's fonts are named by size and width ("40 px Narrow", "Fixed width", "Gear digits") and
  grouped by the Simagic dash they come from, instead of bare numbers. The picker measures your text in each font against the
  box and draws it, shows the fonts the dash already uses, and previews a font on the screen while you hover it. **−** / **+**
  next to the font step to the next smaller / bigger one.
- **Text as the wheel draws it.** The designer and the Exact preview now draw text at the size, width and height on the line
  the wheel uses (it was centred before, a few pixels lower than on the wheel), in the closest Windows font to each screen font.
- **Search in Layers** (Ctrl+F): by name, text, data, condition or page; Enter selects every match. "Only what the screen shows"
  hides the rest.
- **Select several elements:** Shift / Ctrl + click on the screen or in Layers, drag a box on an empty part of the screen, or
  Ctrl+A. Move, nudge, delete, duplicate, copy and paste them together; line them up or space them evenly; put them on a page;
  give their texts one font or colour.
- **Select what's behind:** click an element that's already selected to get the one under it (again for the next), or
  Alt+click. The right-click menu lists everything under the cursor.

**Animated pictures (screensavers)**

- The GIF import window now shows the wheel's screen to scale with your GIF on it, playing what the wheel will actually play
  (the frames kept, the quality, the steps it can't keep up with), not the original GIF.
- A new **Quality** choice: lower quality keeps more frames in the screen's memory and gives the screen less to draw each step,
  at the cost of a softer picture. **Best fit** works for the quality you pick.

**Fixes**

- With picture memory: text that changes under the edge of a picture drawn in front of it no longer shows through that edge.

Everything else is as in [0.7.2](https://github.com/fxunleashed/fx-unleashed/releases/tag/v0.7.2).

### Requirements

SimHub 9.11 or newer, SimPro Manager 3 (V3.2.2 tested) for standard mode, an FX Pro, GT Neo or FX. Tested by the maintainer on one FX Pro
on an Alpha EVO base. The designer and import window changes are checked offline; please report what you find (Discord or GitHub issues).

### Install and update

From 0.5.x, 0.6.x or 0.7.x: let it update itself (About tab). New install: close SimHub, copy `User.FXProRpmSync.dll` from the zip into your SimHub folder, start SimHub,
turn the plugin on. Guide: https://fxunleashed.com/start/

## FX Unleashed 0.5.3

Updates itself from 0.5.2: the banner (or the About tab) offers it, one click installs it, **Roll back** is there if you want the old one.

### What's new

- **The Mustang GT3 is in the library too.** The LMGT3 Ford Mustang GT3 dash that has always come with the plugin is now also an item of the
  [library](https://fxunleashed.com/library/), next to the McLaren 720S GT3 and Toyota GR010 Hybrid, and the library shows it as installed
  (it used to have no library entry). Like the other two it is converted for the FX Pro screen from
  [Redadeg's SimHub dash on lmu-dashboards.com](https://lmu-dashboards.com), and says so in the dash list.

Everything else is as in [0.5.2](https://github.com/fxunleashed/fx-unleashed/releases/tag/v0.5.2).

### Requirements

SimHub 9.11 or newer, SimPro Manager 3 (V3.2.2 tested) for standard mode, an FX Pro or GT Neo. Tested by the maintainer on one FX Pro on an Alpha EVO
base: other bases, wheels and games may behave differently, so please report what you find (Discord or GitHub issues).

### Install and update

From 0.5.0 to 0.5.2: let it update itself (About tab). New install: close SimHub, copy `User.FXProRpmSync.dll` from the zip into your SimHub folder, start SimHub,
turn the plugin on. Guide: https://fxunleashed.com/start/

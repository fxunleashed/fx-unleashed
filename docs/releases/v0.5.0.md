## FX Unleashed 0.5.0

The first stable release under the new name (the plugin was **FXPro RPM Sync** up to 0.2.x). Install it over the old one: same DLL,
same settings file, your settings carry over (the old file is copied to `settings-backup-format0.json` first). After this one the
plugin updates itself.

### What it is

A free SimHub plugin for the Simagic FX Pro (GT Neo too). **Standard mode** works with stock firmware through SimPro: each car's
real shift lights, the dash per car, SimHub's data on the wheel's own dashes. **Unleashed mode** talks to the wheel over its own
USB cable and needs the modified wheel app: your own dashes on the 800x480 screen, all 38 lights in any colour, screensavers,
alerts, a screen mirror for OBS, the dash button and paddles as buttons.

### Highlights since 0.2.x

- **Dashes:** a designer in the browser, SimHub dash import, per-car lists, and the **library** (SLIPSTREAM, APEX, HALO and NOCTURNE
  in three colours, plus a Paddock clock screensaver, more coming), installed in a click from the plugin or from fxunleashed.com.
- **Sharing:** import a dash file (button or drop it on the Dashes tab), **Share** your own as one file, **Copy link** on library
  items, and **Package for the library** + a no-Git form that publishes what passes the checks on the spot.
- **Lights:** 14 presets that follow the car's state, an editor per group, alerts in your order (flags, spotter, ABS/TC, pit
  limiter, low fuel, invalid lap), rev lights from each car's real shift lights (AMS2 from the game's own files, other games from
  Lovely Car Data), ATSR-Hub or any SimHub LED profile as the source.
- **Wheel:** 48 buttons with the dash button and upper paddles chosen by you, clutch modes, live button numbers.
- **Updates:** a banner offers new versions, one click installs, one click rolls back (it also rolls back by itself after three
  failed starts). Stable and Beta channels.
- **GT Neo:** every light in USB mode, ring gauges, the same presets.

### Requirements

SimHub 9.11 or newer, SimPro Manager 3 (V3.2.2 tested) for standard mode, an FX Pro or GT Neo. Tested by the maintainer on one
FX Pro on an Alpha EVO base: other bases, wheels and games may behave differently, so please report what you find.

### Install and update

Close SimHub, copy `User.FXProRpmSync.dll` from the zip into your SimHub folder, start SimHub, turn the plugin on. After that it
updates itself (About tab). (If you tried a beta before beta 3, install this one by hand too: those builds couldn't update themselves.) Guide: https://fxunleashed.com/start/

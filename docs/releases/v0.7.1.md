## FX Unleashed 0.7.1

Updates itself from 0.5.x, 0.6.x and 0.7.0: the banner (or the About tab) offers it, one click installs it, **Roll back** is there if you want the old one.

### What's new

- **Animated GIF screensavers.** "Add a picture" on the Idle tab now takes a GIF, and with picture memory on (Wheel tab) it plays on the
  wheel's screen. A window shows what you'll get before you add it: **Size**, **Smoothness**, a **Best fit** button, how many frames fit
  and how smoothly it will play. A GIF bigger than the screen's memory keeps evenly spaced frames, so the loop stays as long as the GIF's
  (the card says "Oversized: took X/Y frames"). Without picture memory a GIF shows its first frame.
- **Pictures in full colour.** With picture memory on, picture screensavers are now drawn from the screen's memory, in every colour.
  Before, they were drawn with a few colours even though the settings preview showed them in full. Without picture memory, a new
  **pixel size** setting decides how simplified a picture is so it draws in quickly. Pictures you added before keep their old, simplified
  copy: add them again for full colour.
- **Whole screen image (from support).** For the rare screen whose picture-memory upload always ends in "Update Failed": with a file
  from FX Unleashed support, Screen recovery (Wheel tab, Firmware card) can write the screen's whole image once (about 11 minutes),
  after which picture memory turns on as usual. The plugin only accepts the exact image it knows, and the same button is the recovery if
  that upload is interrupted. While any screen upload runs, nothing else in the plugin talks to the wheel, even if SimHub restarts its plugins.
- **Toyota GR010 Hybrid dash, converted again 1:1** from Redadeg's SimHub dash, as in the library (1.1.0): both pages of the bottom bar
  (anti-roll bars, and migration / regen), the original's captions, and less of the screen's memory.

### SimHub import and dash makers

- Pictures turned 90, 180 or 270 degrees in SimHub are imported turned (arrows), copies of the same widget flip together, groups are placed
  from their own corner, script helpers (the dash's own JavascriptExtensions) load on the wheel as in SimHub, a script's PreExpression is
  kept, and text items with SimHub's time behaviours show that time.
- Image elements take a **Block** (pixel size, 1-16) for screens without the RAM drive. `fxdash frames` draws a dash's demo as PNG frames.
- Renderer: a bar on another page, or one hidden under an opaque pop-up, no longer stops the items next to it from being drawn from the RAM
  drive; a bordered box keeps one picture instead of two; page flips no longer show the old page between the new background's strips.

Everything else is as in [0.7.0](https://github.com/fxunleashed/fx-unleashed/releases/tag/v0.7.0).

### Requirements

SimHub 9.11 or newer, SimPro Manager 3 (V3.2.2 tested) for standard mode, an FX Pro or GT Neo. Tested by the maintainer on one FX Pro on an Alpha EVO
base: other bases, wheels and games may behave differently, so please report what you find (Discord or GitHub issues). The animated GIF
screensavers' speed is still being tuned on the wheel: if one plays slowly, tell us which GIF.

### Install and update

From 0.5.x, 0.6.x or 0.7.0: let it update itself (About tab). New install: close SimHub, copy `User.FXProRpmSync.dll` from the zip into your SimHub folder, start SimHub,
turn the plugin on. Guide: https://fxunleashed.com/start/

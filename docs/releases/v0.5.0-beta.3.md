## FX Unleashed 0.5.0 beta 3

**Fixes the updater.** Beta 1, beta 2 and earlier test builds read SimHub's version wrongly (as 1.0.0) and so refused every
update with "it needs SimHub 9.11 or newer". This build reads SimHub's real version. **If you have an earlier build, install this
one by hand once** (below); after that the banner (About tab) updates you.

Also in this build: the wheel app (build 9) is published in its own repository, and the setup text and warning say plainly what it is
(Simagic's wheel app with our changes): https://fxunleashed.com/firmware. The plugin release itself contains no firmware.

Everything else is as in [beta 2](https://github.com/fxunleashed/fx-unleashed/releases/tag/v0.5.0-beta.2): import and share dashes, copy links,
submit to the library without Git, and everything from [beta 1](https://github.com/fxunleashed/fx-unleashed/releases/tag/v0.5.0-beta.1).

### Install by hand

Close SimHub, copy `User.FXProRpmSync.dll` from the zip into your SimHub folder (default `C:\Program Files (x86)\SimHub\`), start SimHub.
Your settings carry over. **Read the [firmware warning](https://github.com/fxunleashed/fx-unleashed/blob/main/docs/legal/firmware-warning.md)
before using Unleashed mode.**

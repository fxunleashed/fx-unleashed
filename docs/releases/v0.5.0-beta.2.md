## FX Unleashed 0.5.0 beta 2

The second test build of 0.5.0. If you have beta 1, **the banner in the plugin (About tab, Beta channel) offers this one**:
that is the update path being tested. If it goes well, the same code becomes the stable 0.5.0.

### New in beta 2

- **Share a dash:** the Dashes tab has **Import a file...** (and you can drop a dash file onto the tab), and **Share...**
  on your own dashes, which writes `<id>.fxdash.json` and puts it on the clipboard. Imported dashes get the library's checks
  (format, size, no scripts) and never overwrite one you have.
- **Copy link** on every library item: a page with a preview and an Install button.
- **Submit to the library without Git:** **Package for the library** now writes a `.fxdash.zip` and opens the library's
  submission form. If the package passes the checks it is published straight away; update it later with a higher Version.
- Converted work in a package needs a link to its author's permission (a new field).
- The wheel setup text names the FX Unleashed wheel app patch and points to fxunleashed.com/firmware.

### Unchanged from beta 1

Everything else: standard and Unleashed mode, the designer, the library, the lights, the updater with Roll back. See the
[beta 1 notes](https://github.com/fxunleashed/fx-unleashed/releases/tag/v0.5.0-beta.1).

### Install and update

Beta 1 users: About tab, Check now, Install. Everyone else: close SimHub, copy `User.FXProRpmSync.dll` from the zip into your
SimHub folder, start SimHub, turn the plugin on. **Read the [firmware warning](https://github.com/fxunleashed/fx-unleashed/blob/main/docs/legal/firmware-warning.md)
before using Unleashed mode**: this release contains no firmware (the wheel app is a separate download, see https://fxunleashed.com/firmware). Guide: https://fxunleashed.com/start/

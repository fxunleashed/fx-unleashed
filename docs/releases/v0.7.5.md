## FX Unleashed 0.7.5

Updates itself from 0.5.x, 0.6.x and 0.7.x: the banner (or the About tab) offers it, one click installs it, **Roll back** is there if you want the old one.

### What's new

- **Rev lights only** (USB mode, Lights tab, next to "Keep them on between sessions"). For when you like SimPro's lights and only
  want each car's real shift lights. With it on, every light stays SimPro's, and the plugin sets the car's shift points in SimPro
  as standard mode does:
  - the buttons and rings are whatever SimPro is set to;
  - the rev lights follow each car, in SimPro's own colours;
  - the light preset, its alerts, the limiter lights and the rev bar extras aren't shown (they need the plugin to draw the lights);
  - SimPro has to be running. Nothing is saved into your SimPro preset: its own rev lights are back when you switch this off or
    close SimHub.

  The switch is kept per wheel. It isn't offered on the FX, and it has no effect with ATSR-Hub's or SimHub's lights.

Why it works this way: over USB a wheel's lights can only be taken all together, so the plugin can't draw just the rev lights and
leave the rest to SimPro.

Everything else is as in [0.7.4](https://github.com/fxunleashed/fx-unleashed/releases/tag/v0.7.4).

### Requirements

SimHub 9.11 or newer, SimPro Manager 3 (V3.2.2 tested) for standard mode and for "Rev lights only", an FX Pro, GT Neo or FX. This
release was tried by the maintainer on a GT Neo on an Alpha EVO base, with a car that has one set of shift lights for every gear;
cars with shift lights per gear use SimPro's own per-gear mode on the GT Neo, which hasn't been tried yet. Please report what you
find (Discord or GitHub issues).

### Install and update

From 0.5.x, 0.6.x or 0.7.x: let it update itself (About tab). New install: close SimHub, copy `User.FXProRpmSync.dll` from the zip into your SimHub folder, start SimHub,
turn the plugin on. Guide: https://fxunleashed.com/start/

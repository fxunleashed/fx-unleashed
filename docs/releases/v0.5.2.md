## FX Unleashed 0.5.2

Updates itself from 0.5.1: the banner (or the About tab) offers it, one click installs it, **Roll back** is there if you want the old one.

### What's new

- **Nine dashes come with the plugin.** Nothing to download: the Mustang GT3, the **McLaren 720S GT3** and **Toyota GR010 Hybrid** (LMU), APEX, HALO,
  SLIPSTREAM and the three NOCTURNEs are in the dash list from the first start, with their credits. The two LMU dashes are converted for the FX Pro
  screen from [Redadeg's SimHub dashes on lmu-dashboards.com](https://lmu-dashboards.com). They are read-only (**Save a copy** to change one),
  the library shows them as installed, and a newer version installed from the library takes their place.
- **Library dashes can carry checked scripts.** A few dashes need a little memory ("show LIFT until the driver brakes"), which takes a `js:` formula.
  That is code SimHub runs, so the library only takes scripts made of a short list of safe parts: no loops, no `eval`, no functions of their own,
  nothing that reaches outside the dash. It is checked when a dash is submitted, over the whole library, and again by the plugin before it installs
  anything. A dash with one says **Contains a checked script** (in the plugin and on the website), and needs this version. The list is in
  [SCRIPTS.md](https://github.com/fxunleashed/fx-unleashed-library/blob/main/SCRIPTS.md); a scripts folder is still never allowed.
- **Library.** The McLaren 720S GT3 and Toyota GR010 Hybrid are in the library too.

Everything else is as in [0.5.1](https://github.com/fxunleashed/fx-unleashed/releases/tag/v0.5.1).

### Requirements

SimHub 9.11 or newer, SimPro Manager 3 (V3.2.2 tested) for standard mode, an FX Pro or GT Neo. Tested by the maintainer on one FX Pro on an Alpha EVO
base: other bases, wheels and games may behave differently, so please report what you find (Discord or GitHub issues).

### Install and update

From 0.5.0 or 0.5.1: let it update itself (About tab). New install: close SimHub, copy `User.FXProRpmSync.dll` from the zip into your SimHub folder, start SimHub,
turn the plugin on. Guide: https://fxunleashed.com/start/
